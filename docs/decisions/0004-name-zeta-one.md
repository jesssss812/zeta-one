# 0004: Name the project Zeta One

Date: 2026-10-27. Status: accepted.

## Decision

The project is **Zeta One**, always shown with a descriptor: "Zeta One: trust and risk checks for AI
agents that move money". The repo name is `zeta-one`.

In control theory ζ is the damping ratio, and ζ = 1 is critical damping: the fastest return to
steady state with no overshoot. It maps onto the product's central trade-off: too little control
lets fraud through, too much challenges legitimate payments. It also echoes Rho's naming, a Greek
letter standing for a precise technical idea.

## Alternatives

Plain "Zeta" was rejected because several companies use it, including Zeta (zeta.tech), a
banking-technology company that already sells AI agents to banks and fintechs, a US couples' money
app, and Zeta Global. A web search on 2026-10-27 found no fintech or AI company named "Zeta One".

## Consequences

- Never write bare "Zeta".
- Say it is a hackathon project built on Rho's API, so the Greek-letter name doesn't read as an
  official Rho product.
- Tagline, explanation, logo idea and design philosophy are in
  [../strategy/messaging.md](../strategy/messaging.md).
